## *Power BI*



##### **Chapter-1 Intro**



###### Intro

* the software tool uses for data visualization and dashboard kind of tasks.



###### Use case

* to get business intelligence
* to get better business understanding
* finds the patterns and related datas on the dashboard
* improve better efficiency
* improve visual story telling



###### why power BI?

* when comes to large number of dataset, doesn't able to remember with human intelligence there comes with software support

&#x20;  like power BI kind of visualization tools to get dashboard designs to interpret business data easily

* to show up multiple files \& system
* to compare different features with plots and diagrams
* update automatically with dynamic datas when incoming of new data, no need to update everytime.



###### Power Bi architecture

* **Data preparation**(from database or datafiles) Power query ----> **Transform** (by main or python defined process) ----> **Visualization**(power BI) ----> **Business user**
